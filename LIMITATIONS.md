# Limitations and verification boundaries

- Original bounded poker roguelike, not an official port or complete Balatro clone. Twenty original passives, seventeen consumables, six bosses, three tags, four vouchers and four normal pack families. No spectral, jumbo/mega packs, altered-category studies, editions/seals, stakes, metaprogression or endless mode.
- Practice recommended. Standard is explicitly experimental: reference baseline targets with sparse original content; greedy simulations won 4/5 Practice and 0/3 Standard seeds. No human balance certification. Final boss ×3 is an original exception. Interest uses pre-reward cash.
- Motion is bounded event-by-event score/source highlighting, not full flying-card choreography. Receipt accounting is immediate. Accessible arrows reorder passives; no drag-and-drop. Original geometric art is deliberately simple.
- UI handler replay is automated; native emulator touch testing covers two legal rounds, receipt/shop/pack/target/voucher and lifecycle, not a full eight-ante touchscreen playthrough. Physical ARM64, notches and broad Android versions remain untested.
- One local checkpoint plus previous-action backup. Legacy migration keeps original archive; unrecoverable files require explicit archived reset. Cancelled target selection is transient; resume returns to persisted pack, not partial selection. No cloud sync or imported commercial-game saves.
- SHA256 detects accidental corruption, not malicious tampering. Flush/rename is not guaranteed power-loss durability without directory fsync. Debug signing remains developmental, not Play Store-ready.
- Test counts are not a substitute for visual quality: parent screenshot review accepted this bounded redesign; APK release publication remains separate.
