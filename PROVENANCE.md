# Asset and source provenance

Original implementation: project contributors, GDScript and procedural UI/card drawing; MIT. No external commercial game assets, source code, logo, soundtracks, or wiki prose are authorized for inclusion. No external audio is planned. Original assets follow MIT unless a specific file documents another license.

The UI owner maintains asset-specific provenance alongside generated assets. Before release, audit `assets/` and `ui/` against that manifest; this document does not certify unseen future additions. Godot's built-in font and engine runtime are third-party components, not original project art; see THIRD_PARTY.md.

Research sources and scope are listed in RESEARCH.md. The commercial game name is used solely to identify inspiration.
