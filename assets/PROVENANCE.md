# Asset provenance

All UI composition, color choices, card layouts, geometric diamond emblems, panels, and explanatory copy were authored originally for Velvet Circuit in `ui/main.gd`. No Balatro images, code, logo, audio, or wiki prose are bundled. No external asset downloads were used. No music or sound is included. Original UI code and generated shapes follow the project license chosen by the integrator.

Text uses Godot’s built-in default font and standard Unicode suit/diamond glyphs (no separate font file). Godot and its bundled font dependencies retain their upstream licenses; the integrator must include Godot third-party notices, rather than applying the project license to engine components.

The UI is drawn at runtime by Godot Control/StyleBoxFlat nodes; there are no raster art source files or hidden paid assets.
